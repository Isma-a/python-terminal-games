# Python Terminal Games

<br>

A collection of classic board games that can be played directly in the command prompt, developed in Python.

<br>

## Available Games

<br>

* **Tic-Tac-Toe** (`tictactoe.py`) **:** A two-player game (local) with turn management, first-player selection (pseudo-random or not), and automatic detection of victory or draw conditions.
* **Connect 4** (`connect_four.py`) **:** Two-player strategy game. Drop your tokens and be the first to align four of them to win.
* **Nim Game** (`nim_game.py`) **:** A strategic math game where two players take turns removing matches from a pile. Don't be the one to take the last match!
* **Find the Number** (`find_the_number.py`) **:** A solo logic puzzle where you must guess a randomly generated secret number within a limited number of attempts using "greater" or "smaller" hints.
* **Slot Machine** (`slot_machine_game.py`) **:** A casino-style game featuring a betting system, spinning reels, and various multiplier payouts based on the symbols you align.
<br>

## How do you play?

<br>

**Requirement :** Make sure Python 3 is installed on your computer.

<br>

1. Clone the repository to your machine :
   ```bash
   git clone https://github.com/TonPseudo/python-terminal-games.git
   ```

2. Access the directory :
   ```bash
   cd python-terminal-games
   ```

3. Run the Python file corresponding to the game you want to play. For example, to play the tictactoe :
   ```bash
   python tictactoe.py
   ```
